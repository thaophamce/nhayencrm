## 3. Kiểm tra cấu hình domain nhayencrm.com

Tìm toàn bộ chuỗi liên quan tới:

- localhost
- 127.0.0.1
- IP cứng
- URL development
- ws://
- http://
- CORS origin
- callback URL
- redirect URL
- cookie domain
- websocket URL
- API base URL

Đánh giá cấu hình production cho:

- `https://nhayencrm.com`
- `https://www.nhayencrm.com` nếu sử dụng.
- API dưới dạng `https://nhayencrm.com/api` hoặc subdomain riêng nếu kiến trúc yêu cầu.
- WebSocket phải sử dụng `wss://`.
- Redirect HTTP → HTTPS.
- Redirect thống nhất www/non-www.
- SPA history fallback.
- Reverse proxy API và WebSocket.
- Upload size.
- Proxy timeout.
- Cache header cho static assets.
- Không cache sai `index.html`.
- Cookie phải phù hợp với HTTPS: Secure, HttpOnly, SameSite và Domain/Path.
- CORS không được dùng `*` khi gửi credential.
- Trusted proxy phải được cấu hình đúng nếu backend chạy sau Nginx.

Hãy đề xuất cấu hình Nginx production hoàn chỉnh nhưng chưa ghi file.

## 4. Kiểm tra biến môi trường và secrets

- Liệt kê tên các biến môi trường bắt buộc cho production, không in giá trị bí mật.
- So sánh code với `.env.example`.
- Phát hiện biến bị thiếu, sai tên hoặc có fallback nguy hiểm.
- Kiểm tra secret/API key/password có bị hard-code hoặc commit vào Git hay không.
- Kiểm tra `.gitignore`.
- Kiểm tra frontend có vô tình bundle secret vào mã client không.
- Phân loại rõ:
  - Biến frontend được phép công khai.
  - Biến chỉ được tồn tại ở backend.
- Tạo đề xuất `.env.production.example` đã che toàn bộ secret.
- Kiểm tra secret mặc định, tài khoản mặc định và mật khẩu yếu.

## 5. Audit bảo mật

Kiểm tra tối thiểu:

- Authentication và session/token.
- Refresh token và thời hạn token.
- RBAC/phân quyền từng API.
- IDOR: người dùng có thể truy cập dữ liệu của người khác bằng cách đổi ID không.
- SQL/NoSQL injection.
- XSS.
- CSRF.
- SSRF.
- Path traversal.
- Open redirect.
- Upload file độc hại.
- MIME type và giới hạn kích thước file.
- Rate limiting.
- Brute-force login.
- Password hashing.
- Logging có làm lộ token, password hoặc dữ liệu cá nhân không.
- CORS.
- WebSocket authentication.
- Security headers:
  - Content-Security-Policy
  - HSTS
  - X-Content-Type-Options
  - Referrer-Policy
  - Permissions-Policy
  - frame-ancestors hoặc X-Frame-Options
- Dependency vulnerabilities bằng công cụ phù hợp với package manager.
- Source map production có làm lộ code hoặc thông tin nhạy cảm không.
- Dev tools, debug endpoint, seed endpoint hoặc test account có bị bật trên production không.

Mỗi vấn đề phải có:
- Mức độ: Critical/High/Medium/Low.
- File và dòng liên quan.
- Kịch bản tác động thực tế.
- Cách khắc phục cụ thể.
- Không báo lỗi chung chung nếu không có bằng chứng.
